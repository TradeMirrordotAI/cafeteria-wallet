# ICT Integration Request — CampusBite

We are proposing a small supervised pilot of CampusBite, a digital cafeteria wallet and ordering system. We would like the service to be accessible from the existing student portal so students do not need another password.

Could the ICT team please confirm:

1. The portal's authentication provider and whether OIDC, SAML 2.0, or a secure one-time server-side handoff is supported.
2. The process for registering an external application and its callback URL.
3. The minimum student identity attributes that may be shared for the pilot (stable student ID, name, student number, active status).
4. How cafeteria staff identities and permissions should be provisioned.
5. Whether a test environment and test student/staff accounts can be provided.
6. Any data protection, hosting, payment, or security requirements the project must meet.

We will not request portal passwords or attempt to access student records directly. Identity verification and role assignment will follow the method approved by ICT.
